# 次の試作で検証する未知の現象 — 3 案

どれも原則は同じ: **透明動物の真値だけを唯一の正解とし、新しい現象もそこから生まれるようにする。**

## 案 1. 足跡の「経年変化」で時刻を読む（水の染み出し・縁の崩れ）

- **現象**: 泥の蹄跡に、時間がたつと周りから水が染み出して溜まり、縁が少しずつ崩れて丸くなる。新しい足跡は縁が鋭く乾いていて、古い足跡は水が溜まって光る。
- **真値とのつながり**: 着地時刻と体重（速度による沈み込みの深さ）だけから、各足跡の状態を決める。
- **確かめたい未知**: 草の起き上がり（今は一様な線形回復）よりも、足跡の形の変化のほうが「何秒前か」をうまく推理させられるか。プレイヤーが足跡を古い順に並べられるか。
- **実装の当て**: 足跡ごとの属性 `aAge` で、水の膜の不透明度と縁の法線のぼかしを変える。地面の湿り気マップを足すと、場所ごとに経年変化の速さが変わる。
- **失敗条件**: 変化が速すぎると見ている間に変わってしまい、遅すぎると差が分からない。60〜300 秒の範囲で、変化が見て分かる段階を 3 つ以上作れるかが鍵。

## 案 2. 雨が透明な体の輪郭を一瞬だけ浮かび上がらせる（間接的な可視化）

- **現象**: 通り雨が降ると、雨粒が透明な動物の背中で弾け、しぶきの点で一瞬だけ輪郭が見える。地面には体が雨を遮った「乾いた影」が残る。
- **真値とのつながり**: 雨粒のレイを動物の当たり判定（Blender の骨に沿ったカプセル）で遮るだけ。見た目は何も描かない。
- **確かめたい未知**: 部分的に見えることで推理が簡単になりすぎるか、それとも「見えたのは本当に動物か」を疑う緊張が生まれるか。乾いた影（動かない痕跡）と、しぶき（一瞬の痕跡）の価値の違い。
- **実装の当て**: GPU パーティクルの雨と、上空からの正射影の深度パスで遮りを計算する（unity-deformablesnow の深度カメラの考え方を上下逆にして使う）。three-mesh-bvh の `shapecast` でカプセルとの当たりを取る。
- **失敗条件**: 雨の密度が高いと輪郭がはっきり見えすぎてゲームが壊れる。雨の降る時間と密度を、ゲームデザインで調整できる変数として扱う必要がある。

## 案 3. 森の音響の遮蔽と反響で、音の方向がずれる

- **現象**: 枝の折れる音が太い幹に遮られてこもり、別の幹で反射した音のほうが大きく届く。音の方向が実際の音源とずれる。
- **真値とのつながり**: 音源の位置（真値）から聞き手へ、幹（Blender の `trunk_radius`）を通る経路を BVH で調べ、直接音の減衰と 1 次反射の向きを決める。
- **確かめたい未知**: 音がずれると、プレイヤーは動いて聞き直し、三角測量のように音源を探すか。それとも理不尽に感じるか。視覚の痕跡（足跡）と聴覚の痕跡（音）が食い違うときに、どちらを信じるか。
- **実装の当て**: 直接音にはローパスとゲインの低下、反射音は反射点に別の `PannerNode` を置いて少し遅らせて鳴らす。環境音の音場だけは Omnitone（FOA）を使う。
- **失敗条件**: ヘッドホンでないと効果が分からない。HRTF の個人差で前後を取り違えやすい。字幕表示（V キー）と矛盾しないように、字幕は「聞こえた方向」を出すのか「真の方向」を出すのかを決めておく必要がある。
